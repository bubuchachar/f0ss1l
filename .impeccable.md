## Design Context

### Users
Developers — people who have written comments like these, left them behind, and moved on. They encounter Fossil while the code is still warm in their hands. They recognise these fossils immediately. The job to be done: feel seen, then feel something.

### Brand Personality
Elegiac. Wry. Inevitable.

Emotional arc per fossil: melancholy first ("something was lost here"), then wry recognition ("I've written this"), then quiet reverence ("it survived"). The ending — "Someone is going to ask." — is not a punchline. It's a fact.

### Aesthetic Direction
Terminal + literary. The visual language IS the argument: old technology (CRT phosphor, monospace, scanlines) mirrors old code. The aesthetic should invoke nostalgia the way Blade Runner and The Matrix do — not cold, not sterile, but warm inside the darkness. Phosphor green glows like something still alive.

**References:** Blade Runner (neon warmth against dark, analog grain), The Matrix (phosphor green, terminal rain, code as poetry), old Unix terminals (not retro-kitsch — earnest and functional).

**Anti-references:** Cold brutalism. Hacker aesthetic played for edge. Generic dark-mode apps (VSCode-grey, flat, no texture). Anything that reads as "developer tool" rather than "literary object". Glassmorphism. Gradient text.

### Color System
```
--green-bright: #00FF41   /* phosphor core — logo, comment block, "Someone is going to ask." */
--green:        #4DFF7C   /* body text, prose, nav — softer, sustained reading */
--green-dim:    #1A6B35   /* borders, labels, dim UI */
--green-faint:  #071A0C   /* recessed surfaces, card backgrounds */
--black:        #060E06   /* background — warmer than pure black */
```

### Typography
- **Press Start 2P** — logo only. Never body copy.
- **Doto** — prose, literary pieces, the literary voice of each fossil.
- **Share Tech Mono** — all UI: navigation, labels, attribution, meta, the comment block itself.
- Paragraph separation: minimum 28px margin-bottom at 15px/1.5 line-height.

### Texture & Effects
- CRT scanlines (repeating-linear-gradient, 4px cycle, 18% opacity) — always on, full viewport, fixed
- CRT vignette (radial-gradient, 60% clear, 60% black at edges) — always on
- Glow on key elements: `0 0 8px rgba(0,255,65,0.6), 0 0 20px rgba(0,255,65,0.2)`
- Soft glow for secondary elements: `0 0 5px rgba(77,255,124,0.35)`
- No gradients on content. No rounded corners. No shadows except phosphor glow.

### Design Principles
1. **The aesthetic is the argument.** The terminal look is not decoration — it carries the meaning. Old tech = old code. Design choices that undermine this (rounded corners, flat color, modern spacing) break the premise.
2. **Warmth within monochrome.** Phosphor green on near-black reads warm, not cold. Protect this. The glow, the vignette, the scanlines all contribute. Never let it feel like a dark-mode productivity tool.
3. **Restraint serves the text.** Nothing competes with the fossil. Animation is subtle (typewriter reveal, opacity fade). Layout is quiet. The comment and the literary piece are the only things that should demand attention.
4. **Consistency as ritual.** Every fossil ends the same way. The design enforces this: same structure, same ending, same glow. Variation is in the content, not the container.
5. **Wry, not precious.** "// Raw mode: 1960 magic shit." belongs here. The design should have enough irreverence to hold that line without flinching.
